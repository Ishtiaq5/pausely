# Pausely - Guided Breathing & Meditation

Pausely is a small, calm web app for guided breathing. Pick a rhythm, follow the glowing orb, and track your calm - no sign-up, no frameworks, no build step.

## Features

- Guided breathing orb with smooth inhale / hold / exhale animation
- Four patterns: Box (4-4-4-4), Relaxed (4-7-8), Calm (4-6) and Coherent (5-5)
- Session stats saved in localStorage: sessions, minutes, breaths and day streak
- Dark premium UI: animated gradient headline, glow accents, glassmorphism panels
- Fully responsive, keyboard friendly and reduced-motion aware

## Run it

Open `index.html` in any modern browser. That's it.

## Structure

- `index.html` - page markup
- `css/styles.css` - theme, layout and animations
- `js/main.js` - breathing engine, presets and stats
